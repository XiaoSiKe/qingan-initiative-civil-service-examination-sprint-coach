青岸不是一份“看起来很努力”的日程表，也不是把十个助手堆到你的 Skill 列表里。

它以大学生的真实备考生活为默认场景：早八、专业课、实验、社团、论文、秋招、实习、宿舍噪音和有限预算都算计划约束，而不是“你不够自律”的证据。它同时是一套通用型考公系统：在职、全职、带娃、二战或其他生活状态的考生，都使用同一个训练闭环，只调整时间与资源适配。

你只需要描述眼前的问题——“还有 80 天怎么排”“这道削弱题为什么错”“今天真的学不动了”——同一个 Skill 会自动选择对应系统，把计划、练习、反馈、错题、情绪支持和回测接成闭环。

```text
诊断起点 → 确定优先级 → 今日三项 → 单题训练 → 错因卡 → 间隔回测 → 周度调参
```

## 🧱 青岸的九个系统

| 系统 | 解决的问题 | 核心机制 |
|---|---|---|
| ① 诊断系统 | 我现在到底卡在哪里？ | 小基线、生活约束、证据分级，不凭感觉判水平 |
| ② 战略系统 | 时间不够，先打哪里？ | 阶段规划、抓主要矛盾、主攻/保持/暂停 |
| ③ 日程适配系统 | 课程、工作和生活怎么放得下？ | 校园/在职/全职/照护适配，碎片与整块任务分流 |
| ④ 学习系统 | 怎样从“看懂”变成“会做”？ | 检索、间隔、交错、自我解释、近变式与迁移 |
| ⑤ 资料系统 | 讲义题册太乱，如何变成训练材料？ | 骨架先行、来源追踪、冲刺卡、短轮自测、增量更新 |
| ⑥ 专项教练系统 | 行测申论每类题怎么练？ | 学科判据、证据链、训练阶梯、考场止损 |
| ⑦ 错题系统 | 为什么错，怎样不再错？ | 第一错误断点、错因聚类、间隔二刷、稳定门槛 |
| ⑧ 效率系统 | 学了多久是否真的有效？ | 正确率、用时、完成率、回测数和周度调参 |
| ⑨ 情绪韧性系统 | 最难受时如何不被一次失败带走？ | 接住—去羞耻—找证据—缩战线—起一步—留回声 |

这些系统不是九个 Skill。它们都内置在同一个青岸入口里，并按当前任务渐进加载。

### 一个 Skill，为什么还能覆盖这些能力？

青岸采用渐进式加载：入口只保留共同规则和路由；识别到当前任务后，只读取相关的内部协议。用户看到的是一个 Skill，模型也不会把十个学科说明同时塞进上下文。

```text
你的自然语言请求
       ↓
青岸统一入口
       ↓
意图判断 ── 安全与情绪优先，错题/计划/资料优先于学科关键词
       ↓
只加载本次需要的 1–2 份训练协议
       ↓
完成解题、训练、批改、计划或记录
```

## 🗓️ 四阶段冲刺

| 剩余时间 | 默认重心 | 不做什么 |
|---|---|---|
| 61 天以上 | 方法基础、专项诊断、首次基线 | 用海量收藏代替训练 |
| 31–60 天 | 高频弱项、间隔回测、模块限时 | 每天平均用力 |
| 8–30 天 | 整卷模拟、时间策略、重复错因修复 | 大规模扩张新体系 |
| 0–7 天 | 已学高频、错题回测、考场流程 | 临时追逐偏难怪题 |

阶段只是默认值。真实错题、正确率、用时和任务完成率会继续修正优先级；没有足够数据时，青岸会明确标记“临时计划”，不会制造精确提分预测。

## 🎒 贴近真实日常，也服务所有考生

| 可用时间 | 适合做什么 |
|---|---|
| 5–15 分钟课间/通勤 | 到期错题口述、政治常识挖空、公式和成语回忆 |
| 25–45 分钟空堂/午休 | 单一题型限时组、申论材料找点 |
| 60–120 分钟晚间/周末 | 弱项修复、模块卷、整篇申论或模考 |
| 状态很差的 10–20 分钟 | 稳定一下、温和回测、一个熟悉题型的小胜利 |

大学生默认考虑课程表、考试周、毕业论文、秋招和实习；在职考生把通勤与加班作为真实输入；全职考生设置停止点避免过量；有照护责任的考生使用可中断任务。身份不同，标准不降，路径不硬套。

## 🧠 方法底座：理论必须落到动作

青岸重点研究了 [`cxs885187-create/--skill`](https://github.com/cxs885187-create/--skill) 的“女娲补天”期末突击工作流。它对青岸最有价值的不是课程内容，而是半自动学习系统：材料证据分级、骨架先行、可直接复习的主题卡、短轮自测、自评校准、连续受挫熔断、保守的掌握表述和增量更新。

该仓库没有独立 `LICENSE` 文件，GitHub 也未识别出许可证，因此青岸把它作为 `concept-only` 研究源：只吸收抽象方法，并围绕考公重新设计，不复制其 Skill 指令、模板或长文本。

| 理论或经典方法 | 青岸中的考公化实现 |
|---|---|
| 检索练习 / 测试效应 | 用户先闭卷答题、口述步骤或写申论要点，再看解析；“看懂”不算掌握 |
| 分散练习 | 错题按默认间隔回测，至少两个不同日期独立成功才稳定 |
| 交错练习 | 专项初步稳定后混合相似题型，训练识别；零基础阶段不强行混练 |
| 费曼式自我解释 | 用自己的话讲“识别信号—步骤—原因—失效条件”，只修错误和遗漏 |
| 康奈尔问题区 | 冲刺卡先呈现问题，参考答案和得分点延后展开，服务主动回忆 |
| 刻意练习 | 一次只修一个可观察弱点，立即反馈，再用近变式验证 |
| 双编码 | 图推、空间、数量关系和申论结构确有需要时才画图或列表 |
| 实施意图 | 把计划写成“如果晚自习 19:30 坐下，就先回测两道旧错题” |

学习科学综述对“练习测试”和“分散练习”的支持较强；自我解释、交错等方法更依赖材料与实施条件。青岸不会把任何名词当万能公式，而会继续用正确率、用时、迁移和完成率检验效果。[学习技术综述](https://doi.org/10.1177/1529100612453266) · [检索练习研究](https://doi.org/10.1111/j.1467-9280.2006.01693.x) · [分散练习综述](https://doi.org/10.1037/0033-2909.132.3.354)

### 从经典哲学转成可执行策略

| 思想 | 在青岸中的含义 |
|---|---|
| 实事求是 | 用题目、错因、时间和完成率说话；没有数据就写临时假设 |
| 实践—认识—再实践 | 做题得到反馈，抽象方法，再回到新题验证 |
| 抓主要矛盾 | 每周只确定一个主攻模块，不平均用力 |
| 具体问题具体分析 | 同样剩 30 天，按基础、考试和生活约束分别设计 |
| 集中优势、各个击破 | 一次集中解决一个错误链，达到完成判据就收兵 |
| 战略持久、局部速决 | 接受备考的阶段性，但让每次训练短而闭环 |

这些思想主要来自《毛泽东选集》中的《实践论》《矛盾论》等经典方法论及相关战略思想的学习转化，只用于帮助分析和行动，不替代题目证据、官方信息或专业支持。[实践与主要矛盾方法导读](http://dsyj.qingdao.gov.cn/llxx_87/mzdsx_87/202202/t20220216_4355379.shtml) · [集中优势与局部主动](https://cpc.people.com.cn/n1/2024/0101/c443712-40150428.html)

## ❤️ 最难受的时候，青岸先接住你

青岸不会说“别人都能做到”“坚持就一定上岸”，也不会用排名、父母期待或沉没成本羞辱你。它会先分开“这次表现”和“你这个人”，再把视野从整场考试缩回今天能控制的一小步。

> 这次低分很刺痛，但它只证明这套题暴露了问题，不证明你不适合考公。今天先不追总进度。给我 15 分钟：回测两道已经见过的题，写下第一个错误断点，时间到就停。你不是要在今晚赢下整场考试，只需要把主动权拿回来一点。

“一万年太久，只争朝夕”在这里意味着把注意力放回今天，不意味着每一分钟都必须学习。状态差时可以使用最低可行训练日；持续耗竭时优先休息、可信任的人和校园/专业支持；出现人身安全风险时，青岸会停止备考推动并优先帮助寻求现实支持。

## ⚙️ 本地效率管理

可选的本地引擎使用 Python 3.9+，不依赖第三方包。它记录学习事件而不是覆盖历史，并从事件重建日计划、周报和错题回测状态。

```bash
cd plugins/qingan-initiative-civil-service-examination-sprint-coach

python3 scripts/qingan.py init \
  --exam-type national \
  --exam-date 2026-11-29 \
  --hours-per-week 20 \
  --study-days-per-week 6 \
  --life-mode campus

python3 scripts/qingan.py today
python3 scripts/qingan.py week-plan
python3 scripts/qingan.py minimum-day --minutes 20
python3 scripts/qingan.py weekly
python3 scripts/qingan.py review-due
```

默认数据目录为 `~/.qingan-gongkao/`，也可通过 `QINGAN_DATA_DIR` 或 `--data-dir` 指定。只有用户明确要求建档、打卡、收录错题或登记资料时才写入；普通讲题不会自动保存。

## 🛡️ 可信度与边界

- `[官方]`：国家公务员局、中国政府网、中央部委或省级主管部门的当前原文。
- `[用户材料]`：保留文件、页码或题目位置，不把培训材料自动当官方答案。
- `[许可开源方法]`：只吸收已登记、许可证兼容且经过独立重写的方法。
- `[AI仿题]`：必须明确标记，不冒充真题。
- `[推断待核]`：证据不足或需要当前信息核验。

看不清的截图、残缺题面和模糊数字不会被补全猜测；申论训练分不冒充官方评分；项目不收录盗版题库、付费课程转写或来源不明的大规模材料。

## 🔒 数据与隐私

权威数据是本地的 `profile.json`、追加式 `events.jsonl` 与 `materials/index.jsonl`。损坏记录会被跳过并报告，不覆盖原文件；迁移和档案更新前会自动备份。项目没有账号系统、云端后台或遥测。
