青岸要解决一个很现实的问题：考试逼近时，怎样把有限时间变成可验证的训练，而不是再添一张写满的计划表。

它以大学生的真实备考生活为默认场景：早八、专业课、实验、社团、论文、秋招、实习、宿舍噪音和有限预算都算计划约束，而不是“你不够自律”的证据。它同时是一套通用型考公系统：在职、全职、带娃、二战或其他生活状态的考生，都使用同一个训练闭环，只调整时间与资源适配。

你只需要描述眼前的问题，比如“还有 80 天怎么排”“这道削弱题为什么错”或“今天真的学不动了”。同一个 Skill 会自动选择对应系统，把计划、练习、反馈、错题、情绪支持和回测接起来。

```text
诊断起点 → 确定优先级 → 今日三项 → 单题训练 → 错因卡 → 间隔回测 → 周度调参
```

## 🧱 系统全景：三层、十二个系统

青岸先决定方向，再组织训练，最后用数据和情绪支持把人留在这条路上。系统之间共享同一份考生状态，不会各说各话。

```text
方向层：我是谁、考什么、先做什么
   ↓
训练层：怎么学、怎么练、怎么改
   ↓
续航层：是否有效、如何坚持、依据是否可靠
   └────────── 用新证据回写方向与训练 ──────────┘
```

### 方向层

| 系统 | 输入 | 核心处理 | 输出给下一步 |
|---|---|---|---|
| ① 考生诊断 | 考试、日期、模考、生活约束 | 建立小基线，区分事实与临时假设 | 当前阶段、最大瓶颈、第一项训练 |
| ② 毛选等哲学思想与冲刺战略 | 剩余时间、错误分布、可用资源 | 实事求是、实践循环、抓主要矛盾、具体分析、集中突破 | 一个主攻、一个保持、一个暂停 |
| ③ 日常生活适配 | 课程、论文、实习、工作、照护、场地 | 把碎片时间和整块时间分给不同任务 | 可执行日程、替代动作、最低可行日 |
| ④ 报考与选岗 | 当年公告、职位表、个人硬条件与偏好 | 先核资格，再比较工作和考试匹配 | 符合/不符合/需确认、职位比较矩阵 |

### 训练层

| 系统 | 输入 | 核心处理 | 输出给下一步 |
|---|---|---|---|
| ⑤ 学习科学 | 当前水平、目标表现、训练结果 | 检索、间隔、交错、自我解释、晋级门槛 | 训练阶梯、回测节点、迁移证据 |
| ⑥ 资料知识库 | PDF、讲义、题册、真题和笔记 | 证据分级、骨架先行、冲刺卡、短轮自测 | 可追溯索引、可直接复习的卡片 |
| ⑦ 行测与申论专项 | 完整题面、用户作答、材料 | 用判据和证据链讲解，再做近变式 | 答案、方法、陷阱、下一次检查 |
| ⑧ 面试训练 | 当年面试公告、题目、口述或文字作答 | 一次一题、先答后评、针对一个断点二答 | 稳定点、主修项、二答变化 |
| ⑨ 错题复盘 | 题目、答案、过程、用时 | 找第一错误断点，按错因聚类并安排回测 | 最小修正、二刷日期、稳定状态 |

### 续航层

| 系统 | 输入 | 核心处理 | 输出给下一步 |
|---|---|---|---|
| ⑩ 考公效率评估 | 时长、题量、正确率、完成率、回测 | 分看执行、准确、时间、闭环和证据，不造综合分 | 置信度、唯一瓶颈、下周只改一件事 |
| ⑪ 情绪价值与韧性 | 低分、过载、自我怀疑、疲惫 | 接住、去羞耻、找证据、缩战线、起一步 | 可控感、10–20分钟小胜利、现实支持 |
| ⑫ 证据与更新 | 官方公告、用户材料、许可开源方法 | 核对时效、标注来源、隔离推断和模拟题 | 可追溯结论、核验日期、更新提示 |

这十二个系统都内置在同一个 Skill 中。用户只管说问题，青岸负责决定先进入哪个系统、何时把结果交给下一个系统。

## 🗣️ 青岸怎么讲：先说人话，再讲方法

讲题顺序固定为：一句话说清问题 → 给本题判据 → 走一步小例子 → 指出反例或陷阱 → 让考生自己完成下一步。公式会解释每个符号和单位，逻辑题会画清箭头方向，申论会展示材料原句怎样变成答案要点。

| 生硬说法 | 青岸会怎么说 |
|---|---|
| “该选项未能有效削弱论点” | “它说的可能是真的，但没有碰到题干那座桥，所以削不动。” |
| “建议优化时间管理能力” | “这份计划一天塞了四小时，而你只有两节空课。不是你执行差，是计划先吹牛了。” |
| “申论答案缺乏有效信息” | “你写了态度，但材料里的主体、动作和结果还没搬进答案，所以阅卷人没点可踩。” |

幽默是调味，不是主菜。状态稳定时可以轻轻来一句：“错题本别做成赛博垃圾桶，进去以后得安排它出来复试。”用户难受、讨论政策或存在安全风险时不玩梗。青岸不拿分数、专业、家庭和失败开玩笑。

### 一个 Skill，为什么还能覆盖这些能力？

青岸采用渐进式加载：入口只保留共同规则和路由；识别到当前任务后，只读取相关的内部协议。用户看到的是一个 Skill，模型也不会把十个学科说明同时塞进上下文。

```text
你的自然语言请求
       ↓
青岸统一入口
       ↓
意图判断 ── 安全与情绪优先，错题/计划/资料优先于学科关键词
       ↓
只加载本次需要的 1–2 份训练协议
       ↓
完成解题、训练、批改、计划或记录
```

## 🗓️ 四阶段冲刺

| 剩余时间 | 默认重心 | 不做什么 |
|---|---|---|
| 61 天以上 | 方法基础、专项诊断、首次基线 | 用海量收藏代替训练 |
| 31–60 天 | 高频弱项、间隔回测、模块限时 | 每天平均用力 |
| 8–30 天 | 整卷模拟、时间策略、重复错因修复 | 大规模扩张新体系 |
| 0–7 天 | 已学高频、错题回测、考场流程 | 临时追逐偏难怪题 |

阶段只是默认值。真实错题、正确率、用时和任务完成率会继续修正优先级；没有足够数据时，青岸会明确标记“临时计划”，不会制造精确提分预测。

## 🧠 方法底座：理论必须落到动作

青岸重点研究了 [`cxs885187-create/--skill`](https://github.com/cxs885187-create/--skill) 的“女娲补天”期末突击工作流。课程内容没有进入项目，青岸吸收的是半自动学习系统这一层：材料证据分级、骨架先行、可直接复习的主题卡、短轮自测、自评校准、连续受挫熔断、保守的掌握表述和增量更新。

该仓库没有独立 `LICENSE` 文件，GitHub 也未识别出许可证，因此青岸把它作为 `concept-only` 研究源：只吸收抽象方法，并围绕考公重新设计，不复制其 Skill 指令、模板或长文本。

| 理论或经典方法 | 青岸中的考公化实现 |
|---|---|
| 检索练习 / 测试效应 | 用户先闭卷答题、口述步骤或写申论要点，再看解析；“看懂”不算掌握 |
| 分散练习 | 错题按默认间隔回测，至少两个不同日期独立成功才稳定 |
| 交错练习 | 专项初步稳定后混合相似题型，训练识别；零基础阶段不强行混练 |
| 费曼式自我解释 | 用自己的话讲“识别信号—步骤—原因—失效条件”，只修错误和遗漏 |
| 康奈尔问题区 | 冲刺卡先呈现问题，参考答案和得分点延后展开，服务主动回忆 |
| 刻意练习 | 一次只修一个可观察弱点，立即反馈，再用近变式验证 |
| 双编码 | 图推、空间、数量关系和申论结构确有需要时才画图或列表 |
| 实施意图 | 把计划写成“如果晚自习 19:30 坐下，就先回测两道旧错题” |

学习科学综述对“练习测试”和“分散练习”的支持较强；自我解释、交错等方法更依赖材料与实施条件。青岸不会把任何名词当万能公式，而会继续用正确率、用时、迁移和完成率检验效果。[学习技术综述](https://doi.org/10.1177/1529100612453266) · [检索练习研究](https://doi.org/10.1111/j.1467-9280.2006.01693.x) · [分散练习综述](https://doi.org/10.1037/0033-2909.132.3.354)

来源多不等于规则多。只有能提高判断、训练或验证质量的方法才进入统一协议；相互冲突时，以青岸的官方来源、用户真实数据和单 Skill 架构为准。

花生十三方向的精确请求（ABRX、415 份数、截位直除、假设分配）会先走青岸的资料分析速算协议；若宿主已安装 `gongkao-huasheng13`，可直接调用它辅助解释，答案仍由青岸核算并复盘。普通资料分析问题无需安装外部 Skill。

### 从经典哲学转成可执行策略

| 思想 | 在青岸中的含义 |
|---|---|
| 实事求是 | 用题目、错因、时间和完成率说话；没有数据就写临时假设 |
| 实践—认识—再实践 | 做题得到反馈，抽象方法，再回到新题验证 |
| 抓主要矛盾 | 每周只确定一个主攻模块，不平均用力 |
| 具体问题具体分析 | 同样剩 30 天，按基础、考试和生活约束分别设计 |
| 集中优势、各个击破 | 一次集中解决一个错误链，达到完成判据就收兵 |
| 战略持久、局部速决 | 接受备考的阶段性，但让每次训练短而闭环 |

这些思想主要来自《毛泽东选集》中的《实践论》《矛盾论》等经典方法论及相关战略思想的学习转化，只用于帮助分析和行动，不替代题目证据、官方信息或专业支持。[实践与主要矛盾方法导读](http://dsyj.qingdao.gov.cn/llxx_87/mzdsx_87/202202/t20220216_4355379.shtml) · [集中优势与局部主动](https://cpc.people.com.cn/n1/2024/0101/c443712-40150428.html)

## ❤️ 最难受的时候，青岸先接住你

青岸不会说“别人都能做到”“坚持就一定上岸”，也不会用排名、父母期待或沉没成本羞辱你。它会先分开“这次表现”和“你这个人”，再把视野从整场考试缩回今天能控制的一小步。

> 这次低分很刺痛，但它只证明这套题暴露了问题，不证明你不适合考公。今天先不追总进度。给我 15 分钟：回测两道已经见过的题，写下第一个错误断点，时间到就停。你不是要在今晚赢下整场考试，只需要把主动权拿回来一点。

“一万年太久，只争朝夕”在这里意味着把注意力放回今天，不意味着每一分钟都必须学习。状态差时可以使用最低可行训练日；持续耗竭时优先休息、可信任的人和校园/专业支持；出现人身安全风险时，青岸会停止备考推动并优先帮助寻求现实支持。

## 📏 考公效率怎么评估

青岸不发一个“今日效率 83 分”糊弄人。它分开看五件事：

| 维度 | 核心问题 |
|---|---|
| 执行 | 任务是否按真实时间预算完成，还是计划本身太大？ |
| 准确 | 同类题正确率和第一错误断点有没有改善？ |
| 时间 | 在题型、难度和计时条件可比时，单位时间有效产出是否变化？ |
| 回测 | 错题有没有按期再做，提示依赖有没有下降？ |
| 证据 | 样本量和前后条件够不够支撑趋势判断？ |

评估结果包含 `low / medium / high` 置信度、一个当前瓶颈和一条调整动作。题源或难度变了，就不硬比较；数据太少，就先建立基线。它评的是训练过程，不给考生本人打分。

```bash
python3 plugins/qingan/scripts/qingan.py evaluate
```

## 🛡️ 可信度与边界

- `[官方]`：国家公务员局、中国政府网、中央部委或省级主管部门的当前原文。
- `[用户材料]`：保留文件、页码或题目位置，不把培训材料自动当官方答案。
- `[许可开源方法]`：只吸收已登记、许可证兼容且经过独立重写的方法。
- `[AI仿题]`：必须明确标记，不冒充真题。
- `[推断待核]`：证据不足或需要当前信息核验。

看不清的截图、残缺题面和模糊数字不会被补全猜测；申论训练分不冒充官方评分；项目不收录盗版题库、付费课程转写或来源不明的大规模材料。

## 🔒 数据与隐私

权威数据是本地的 `profile.json`、追加式 `events.jsonl` 与 `materials/index.jsonl`。损坏记录会被跳过并报告，不覆盖原文件；迁移和档案更新前会自动备份。项目没有账号系统、云端后台或遥测。
