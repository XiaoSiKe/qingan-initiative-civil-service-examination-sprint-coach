# 错因分类与错因卡

## 分类

| 类型 | 判断依据 | 修正方向 |
|---|---|---|
| knowledge | 不知道规则、概念、公式或事实 | 补最小知识卡后立刻回测 |
| recognition | 学过但没有识别出题型或信号 | 训练识别信号和反例 |
| reading | 主体、时间、范围、否定词或单位读错 | 建立审题检查项 |
| reasoning | 关系链、论证方向或条件转换错误 | 重做关键推理步骤 |
| calculation | 公式、代入、估算、精度或运算错误 | 固定计算顺序与验算 |
| strategy | 做题顺序、时间分配或取舍错误 | 设置止损点和跳题规则 |
| careless | 方法正确且能复现，只在执行中偶发失误 | 增加一个具体检查动作 |
| unknown | 证据不足 | 标低置信并说明缺什么 |

不要把无法解释的错误都归为粗心。
