# 青岸错题复盘

支持三种输入：截图、完整文字题、`模块-题型-错因-待二刷` 快捷记录。

## 复盘流程

1. 还原用户实际看到的题面、选项、用户答案和参考答案；缺失处明确标空。
2. 识别模块与题型，再调用对应青岸学科方法。
3. 沿“知识 → 识别 → 审题 → 推理/计算 → 策略 → 检查”定位第一个断点。
4. 给出最小修正、下次固定动作和一道变式回测。
5. 用户明确说记录、收录或加入错题本时，才运行 `record-error --json`。若错题属于已记录的整场练习，传入该会话返回的 `session_id`，避免周报重复计数。

错误类型和输出卡见 [references/error-taxonomy.md](references/error-taxonomy.md)。

## 图片边界

- 必须先实际查看图片；不能只看路径或 OCR 摘要。
- 数字、图形或选项看不清时，不补全、不猜答案，只指出需要补充的区域。
- 最多追问一个问题，优先问影响诊断的缺失信息。
- 图像识别能力不可用时，请用户粘贴文字，不中断已有分析。

## 回测

记录错题后默认次日回测。用户用 `again/hard/good/easy` 评价回测，再运行 `rate-review`。至少两次不同日期的成功回测且达到阶段 2，才标记 `stable`。
