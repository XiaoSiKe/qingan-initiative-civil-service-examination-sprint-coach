# 青岸资料整理

用户材料决定训练范围，外部知识只用于核验或解释，不能偷偷替换材料。

## 工作流

1. 按文件名、标题和可见内容把材料归到考试类型与模块，标记高/中/低置信度。
2. 区分框架证据、知识证据、题型证据和答案证据；低置信资料进入“待确认”。
3. 有文件系统时，用 `register-material --json` 登记路径、SHA-256、类型和范围说明。
4. 先建立模块骨架，再生成少量能直接复习或自测的学习卡。
5. 新材料加入时判断为新增、替换、可能重复或待确认，只更新受影响内容。

详细格式见 [references/material-protocol.md](references/material-protocol.md)。

## 边界

- 无法读取文件时说明能力缺口，不声称已处理。
- 用户资料与外部资料冲突时，以当年官方文件为制度事实源；学习范围冲突则优先用户明确指定的考试资料。
- 材料没有答案时，生成的解答标记 `[AI推断待核]`。
- 不批量导入来源不明题库、盗版课程、私人转写或第三方付费内容。
