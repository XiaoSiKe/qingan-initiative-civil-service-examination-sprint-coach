# 路由协议

| 用户意图 | 目标 Skill | 识别信号 |
|---|---|---|
| 错题复盘 | `qingan-mistake-review` | 错题、截图、我选了、正确答案、为什么错、二刷 |
| 冲刺管理 | `qingan-sprint-manager` | 几个月、倒计时、计划、今日、周报、打卡、效率 |
| 资料学习 | `qingan-materials` | PDF、讲义、笔记、题册、材料、帮我整理 |
| 言语 | `qingan-verbal` | 主旨、意图、细节、排序、填句、逻辑填空、成语 |
| 图推 | `qingan-figure` | 图形、九宫格、位置、样式、数量、空间重构 |
| 逻辑 | `qingan-logic` | 定义、类比、翻译、真假、削弱、加强、前提 |
| 数资 | `qingan-data-quant` | 资料分析、增长率、比重、数量、工程、行程、概率 |
| 政治与常识 | `qingan-politics` | 政治理论、常识、公基、时政、法律、科技、文史 |
| 申论 | `qingan-shenlun` | 概括、分析、对策、应用文、作文、申论批改 |

冲突时采用以下规则：

1. “这道资料分析错题为什么错”先做错题诊断，再使用数资方法。
2. “根据这份讲义出言语题”先登记和核验资料，再使用言语方法。
3. “最近逻辑总错，安排下周”先用周度数据定优先级，再进入逻辑训练。
4. 用户点名青岸但请求已明确时，保留青岸口径并直接进入专项，不重复介绍功能。
