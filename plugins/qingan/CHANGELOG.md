# Changelog

本项目遵循 Semantic Versioning。

## 0.4.0 - 2026-09-09

- 将 README 的能力框架重组为“方向—训练—续航”三层十二系统，为哲学思想、效率评估和情绪价值提供独立、统一的模块说明。
- 新增考公效率评估协议与 `evaluate` 命令，分别评估执行、准确、时间、回测、覆盖和证据质量，不生成伪精确综合分。
- 新增通俗讲解、亲和与幽默协议：先说人话、再给判据、小例子、反例和用户下一步；严肃场景自动收起幽默。
- 新增报考选岗与面试训练路由，强制核对当年官方信息，并采用一次一题、先答后评、针对性二答。
- 深化 `kaogong-study-tracker`、`universal-examprep-skill`、`learn-anything-fast`、`redscarf-gongkao-skills` 与 `kaogong-skill` 的兼容许可证方法蒸馏。
- 新增 MIT-0 来源 `Zhaojixu/shangan-gongkao`，仅吸收多时间窗计划与资料角色分类，不分发其材料清单。
- 行为场景扩展到 60 个，覆盖 14 条内部路由和跨路由冲突。

## 0.3.0 - 2026-09-09

- 在 README 主标题下加入“一万年太久，只争朝夕！”，并用九个系统说明青岸的完整能力。
- 以大学生课程、论文、秋招、实习、宿舍和碎片时间为默认生活场景，同时增加在职、全职、照护责任和混合状态适配。
- 重点研究 `cxs885187-create/--skill`，独立实现骨架先行、冲刺卡、短轮自测、自评校准、受挫熔断、保守掌握语言和增量更新。
- 新增学习科学与策略哲学协议，把检索/间隔/交错、自我解释、实施意图，以及实践、主要矛盾、具体分析、集中突破等方法转成训练动作。
- 新增情绪韧性路由，提供低谷支持、羞耻隔离、最小行动恢复与安全风险边界。
- 本地引擎新增生活模式、每周学习日和 `minimum-day` 最低可行训练日，同时兼容 v0.1/v0.2 的 schema v1 档案。
- 行测、申论、资料、错题、冲刺和来源系统增加训练阶梯与方法边界。
- 将内部插件路径收敛为 `plugins/qingan`，避免正式英文长名称在 Windows checkout 中触发路径长度限制。

## 0.2.0 - 2026-09-09

- 将正式英文名确定为 **Qing'an Initiative · Civil Service Examination Sprint Coach**，并统一更新插件、Skill 与发布包标识。
- 将原先分散的专项入口收敛为 1 个统一 Skill，通过内部路由按需加载训练协议。
- 扩充首次诊断、训练闭环、冲突路由、材料增量、错因定位和九大学科协议。
- 为日计划增加时间预算与完成判据，新增 `week-plan` 主攻/保持/回测周计划。
- 周报新增正确率、任务完成率和优先级依据，同时保持 v0.1.0 本地数据格式兼容。
- 重写 README，增加徽章、能力地图、安装示例、冲刺阶段、折叠说明与隐私边界。

## 0.1.0 - 2026-09-09

- 建立考公冲刺总入口与专项训练能力。
- 增加本地学习事件、错题回测、日计划、周报、资料登记与导出工具。
- 增加来源、许可证、上游更新和发布包校验。
- 增加跨平台单元测试与行为场景集。
