# 逻辑分题型协议

- 定义判断：拆主体、行为、目的、条件、结果；逐项做要件匹配。
- 类比推理：先写词项关系，再比较关系顺序、必然性和层级。
- 翻译推理：统一符号，检查逆否，不把否前或肯后当有效推理。
- 真假推理：先找矛盾/反对关系，再用题目给定真假数量约束。
- 削弱加强：确定论点、论据和缺口；比较选项是否直击缺口及作用强度。
- 前提假设：优先用否定代入检查论证是否失去成立基础。

## 强度比较

削弱/加强先判断是否触及论点与论据之间的缺口，再比较直接性、范围和确定性。选项自身真实、常见或态度鲜明，不等于对论证作用更强。前提题的正确项应是论证成立所必需，而不只是有帮助。

条件推理把“如果 A，那么 B”写成 `A → B`，只允许逆否 `¬B → ¬A`；除非题干另有双向条件，不做肯后或否前。集合、真假和排列问题先写约束，再检验候选，不依赖直觉补前提。

输出固定为：题型 → 关系图/要件 → 判据 → 选项作用 → 结论 → 错因。

## 训练阶梯

先让用户只写论点/定义要件/条件式，不急着选答案；结构抽取稳定后再做选项强度比较，最后混入相邻题型检验识别。削弱加强错题必须记录选项作用位置（论点、论据、桥梁或无关），条件推理错题必须写出发生了哪一种非法转换。
