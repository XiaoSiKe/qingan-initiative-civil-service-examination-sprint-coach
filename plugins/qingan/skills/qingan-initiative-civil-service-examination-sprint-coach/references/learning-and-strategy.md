# 学习科学与策略哲学

方法的价值在于改变训练动作。不要只列理论名，也不要把历史或学习理论包装成提分保证。

## 从重点研究源蒸馏的考公工作流

`cxs885187-create/--skill` 提供了期末突击的概念启发。研究快照固定在提交 `aa0467bd848ce40000e0bdd80667d4f24d946bc3`。该仓库没有独立 `LICENSE` 文件，因此青岸只做概念研究并独立实现，不复制其指令和模板。

1. **先建骨架**：把资料压到“考试—模块—题型—方法—陷阱—来源”，再写摘要。
2. **资料分级**：官方当年文件、用户真题/讲义、可核验解释源分层，低置信材料进入待确认。
3. **卡片必须可训练**：每张冲刺卡回答“考什么、怎么识别、怎么做、哪里易错、如何自测、来源在哪”。
4. **短轮自测**：每轮 3–5 题，用户先闭卷，再看依据或得分点。
5. **自评校准**：使用“独立正确 / 有提示正确 / 不会 / 超时”，由结果决定下一轮，而不是由模型宣布掌握。
6. **受挫熔断**：连续三项“不知道/不会”，停止继续出题，回到对应冲刺卡重建后再换题验证。
7. **保守掌握语言**：未训练、重建中、一次回忆通过、迁移待验证、间隔回测稳定。
8. **增量更新**：新资料只更新受影响的骨架、卡片和自测，不推倒全部成果。

其他兼容来源继续补强三点：`learn-anything-fast` 的晋级门槛要求学习者拿出独立作答证据；`universal-examprep-skill` 的讲解切片要求一屏只推进一个概念；`Zhaojixu/shangan-gongkao` 的多时间窗与资料角色用于选择计划粒度。它们都服从青岸的题源、时效和单 Skill 边界。

## 著名学习方法如何落地

| 方法 | 青岸中的动作 | 使用边界 |
|---|---|---|
| 检索练习 / 测试效应 | 先闭卷回答、口述步骤或写申论要点，再看答案 | 看懂解析不算会；题源和答案身份必须清楚 |
| 间隔练习 | 错题按 1、3、7、14、30 天回测，两次不同日期成功才稳定 | 间隔是默认启发式，考试临近时可压缩 |
| 交错练习 | 专项稳定后混合相似题型，训练识别而非套公式 | 零基础时先分块，不一开始就全混 |
| 费曼式自我解释 | 用自己的话讲“识别信号—步骤—原因—失效条件” | 只修错误与遗漏，不追求表演式长解释 |
| 康奈尔问题区 | 冲刺卡以问题提示组织，答案或得分点延后展开 | 结构服务回忆，不强迫所有笔记长成同一模板 |
| 刻意练习 | 选一个可修复弱点，得到即时反馈，再做近变式 | 不是机械刷更难的题，也不是无限延长时长 |
| 双编码 | 图推、空间、数量关系和申论结构必要时配图/表 | 只在图能减少理解成本时使用，不做装饰 |
| 实施意图 | 写成“如果到晚自习 19:30，就先回测两道错题” | 计划必须基于真实场景，并设置失败后的替代动作 |

学习科学综述对“练习测试”和“分散练习”的支持较强，对自我解释、交错等方法的效果更依赖材料和实施条件。青岸因此把方法当默认策略而非万能公式，并优先记录真实正确率、用时和迁移结果。

## 从《毛泽东选集》等经典方法论转成训练策略

| 思想 | 考公化解释 | 可执行动作 |
|---|---|---|
| 实事求是 | 用题目、时间和错因说话，不按焦虑想象能力 | 先做小基线，再定计划；无数据就标临时假设 |
| 实践—认识—再实践 | 做题得到经验，抽象方法，再回到新题验证 | 尝试 → 反馈 → 冲刺卡 → 变式 → 间隔回测 |
| 抓主要矛盾 | 一个阶段只解决最制约总表现的瓶颈 | 周计划只设一个主攻、一个保持、一个暂停 |
| 具体问题具体分析 | 同样剩 30 天，不同基础和生活约束不能套同一表 | 按考试、题型、生活模式和证据动态调整 |
| 集中优势、各个击破 | 不平均用力，把有限精力集中到高价值小战役 | 单次只打一个错误链，达到完成判据就收兵 |
| 战略持久、局部速决 | 整体备考接受阶段性，单次训练必须短而闭环 | 长周期按阶段推进；每日任务有时间盒与停止点 |

这些思想只作为学习与行动的方法论，不替代题目证据、官方考试信息或心理专业支持。

## 时间窗与资料角色

根据剩余时间选择最小够用的观察窗：60/30 天看阶段，15/7 天看训练循环，3/1 天只做收束与考场准备。时间窗不是固定模板；真实考试日和可用小时优先。

资料只分三种角色：`核心` 用于建立方法骨架，`刷题` 用于检索和迁移，`查漏` 只在暴露缺口时读取。一本资料可以在不同阶段换角色，但不能因为文件多就全部列为必学。
