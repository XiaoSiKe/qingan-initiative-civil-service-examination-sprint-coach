# 外部 Skill 联动

青岸默认使用统一 Skill 内置协议，不要求安装任何上游项目。

只有用户明确点名外部方法，且宿主的 Skill 清单中确实存在对应 Skill 时，才允许联动。例如用户说“用红领巾方法复盘”，可调用已安装的 `redscarf-*`。外部能力只作为本次辅助，不变成青岸对外暴露的新 Skill。调用后必须：

1. 保留外部方法的来源标签和不确定性。
2. 不把外部输出整段复制进青岸资料库。
3. 只把用户本题的题型、错误环节、修正动作和回测计划写入青岸事件结构。
4. 外部 Skill 不存在时，直接使用青岸统一入口中的对应内部协议，不要求用户安装。
5. GPL、AGPL 或未声明许可证的 Skill 可以由用户单独调用，但其源码和长文本不得进入青岸 MIT 发布包。
