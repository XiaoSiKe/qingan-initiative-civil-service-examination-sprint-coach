# 外部 Skill 联动

青岸默认使用统一 Skill 内置协议，不要求安装任何上游项目。

只有用户明确点名外部方法，或请求精确对应的速算方法，且宿主的 Skill 清单中确实存在对应 Skill 时，才允许联动。例如用户说“用红领巾方法复盘”，可调用已安装的 `redscarf-*`。

花生十三专项的对应关系：用户明确说“花生十三”或请求 `ABRX`、`415 份数`、`截位直除`、`假设分配` 时，若已安装 `gongkao-huasheng13`，可直接调用它辅助解释该方法或分析该题；同时使用青岸的 `rapid-calculation.md` 核算关系式、近似精度和答案。普通资料分析、数量关系、申论或套题请求不因领域重合而自动调用外部 Skill。缺题面、图片不可读、用户要求先作答时，沿用青岸的缺证据与不提前泄题规则。

外部能力只作为本次辅助，不变成青岸对外暴露的新 Skill。调用后必须：

1. 保留外部方法的来源标签和不确定性。
2. 不把外部输出整段复制进青岸资料库。
3. 只把用户本题的题型、错误环节、修正动作和回测计划写入青岸事件结构。
4. 外部 Skill 不存在时，直接使用青岸统一入口中的对应内部协议，不要求用户安装。
5. GPL、AGPL 或未声明许可证的 Skill 可以由用户单独调用，但其源码和长文本不得进入青岸 MIT 发布包。
