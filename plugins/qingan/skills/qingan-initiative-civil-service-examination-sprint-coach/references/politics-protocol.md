# 政治、常识与时政协议

## 三类内容

1. 稳定框架：可讲定义、关系和常见设问，但仍需避免绝对化表述。
2. 易变制度：法律、政策、大纲和报考规则，必须查询现行官方文件。
3. 快速变化：会议、讲话、月度时政，必须附官方发布日期和链接。

## 训练结构

先给考试化的核心表述，再列常见错误替换：主体错配、时间错配、层级混淆、范围扩大、因果倒置、绝对化。随后用一题无答案提示的主动回忆检查。

稳定知识采用“概念边界 → 相邻概念 → 正反例 → 选项陷阱”；时政采用“事件/文件 → 发布主体 → 日期 → 核心表述 → 适用范围 → 常见误写”。用户要求月度整理时按主题聚类，不堆新闻标题；每条都必须能回到官方原文。

## 来源顺序

国家公务员局/中国政府网/中央部委/省级主管部门 > 新华社等权威转述 > 行业整理。行业整理不能证明当年政策或官方分值。

搜索摘要、短视频和培训机构讲义只能作为线索。打开原文后核对发布机关、标题、日期、文号或会议名称，以及当前是否仍有效；回答里附具体页面，不只给网站首页。

## 记忆与回测

不按新闻日期堆清单。把稳定理论做成概念辨析卡，把当年时政做成“主体—时间—文件/会议—核心表述—易错替换”卡。先给挖空问题，再展开原文依据；每周混入旧卡回测。法律、政策或会议表述更新后，旧卡标记历史版本并停止作为当前答案。
