# 来源与时效协议

## 来源标签

- `[官方]`：国家公务员局、中国政府网、中央部委、各省组织人事或考试主管部门。
- `[用户材料]`：用户上传的题目、讲义、答案或批注，需标注文件和页码/位置。
- `[许可开源方法]`：有兼容许可证且已登记的开源方法，只能描述实际证据。
- `[AI仿题]`：模型根据已知题型生成，绝不能称为真题。
- `[推断待核]`：证据不足的分析或临时假设。

## 信息优先级

当年官方公告 > 用户提供的当年官方文件 > 长期有效法规 > 权威媒体转述 > 行业整理 > 模型记忆。

涉及报名时间、年龄、职位条件、考试大纲、时政、法律变动、题量或分值时，先查询当前官方文件。行业题量和分值统计必须标明“非官方口径”。无法访问最新来源时，提供核验路径，不给确定结论。

## 题目与评分

- 用户材料中的“参考答案”不自动等于官方答案，应保留来源标签。
- 申论建议分数只作训练参考，并列出踩点证据与信息缺口。
- 生成客观题前检查唯一答案、设问方向、干扰项层级和解析闭环。
- 不收录来源不明的大规模题库、课程转写、OCR 讲义或付费材料。

## 方法论证据

学习方法区分三层：系统综述/可重复研究支持、经典教学法或生产力启发、青岸基于考公场景的工程化启发式。不得把帕累托、番茄钟、艾宾浩斯曲线或人物名言描述成对所有考生有效的科学定律。说明适用条件，并以用户真实正确率、用时、迁移与完成率继续检验。

外部仓库即使 README 自述开源，只要缺少独立许可证文件或 GitHub 无法识别许可证，仍按 `concept-only` 处理：可以研究抽象方法，不能复制指令、模板或大段文字。
