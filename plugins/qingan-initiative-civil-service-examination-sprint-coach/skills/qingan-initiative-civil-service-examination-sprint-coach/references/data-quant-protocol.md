# 数资协议

## 资料分析

按“定位材料 → 明确现期/基期 → 写关系式 → 判断精度 → 对选项”执行。高频关系包括增长率、增长量、比重、平均数、倍数和两期比较。每题最后检查主体、时间和单位。

常用关系必须先写清变量含义：现期 = 基期 × (1 + 增长率)；增长量 = 现期 − 基期；比重 = 部分 / 整体；平均数 = 总量 / 份数。公式只是关系，不替代题干的主体、时期和单位核对。

估算前先看选项差距。能用范围或首位区分时不追求高精度；差距接近时升级为直除或精算。任何近似都要能说明误差不会跨过选项边界。

## 数量关系

按“题型信号 → 可否代入/赋值 → 建模步骤 → 计算成本 → 执行或跳过”执行。优先利用整除、奇偶、范围和选项特征，但不得把技巧当成证明。

优先比较四条路径：代入选项、赋特殊值、枚举/画表、列方程。选择能在考场时间内验证答案的最短可靠路径；若建模信号不清或计算量明显超出个人止损线，先跳题并记录“识别/策略”问题，而不是事后展示复杂解法。

## 复盘

记录错误发生在材料定位、关系式、运算、精度、单位还是时间策略，并给出下次可观察的具体动作。
