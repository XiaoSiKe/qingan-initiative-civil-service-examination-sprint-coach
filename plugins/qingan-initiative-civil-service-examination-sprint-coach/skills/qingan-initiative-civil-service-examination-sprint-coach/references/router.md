# 单 Skill 内部路由协议

路由只决定本次要读取的协议与回答形态，不对用户暴露多个 Skill。先按任务动作判断，再看学科名；不要只做关键词匹配。

## 主路由

| 路由 | 用户真正要完成的动作 | 识别信号 | 加载协议 |
|---|---|---|---|
| `diagnosis` | 建立起点和完整冲刺路径 | 第一次、零基础、完全不知道、整体安排、跨模块 | `training-loop.md`、`sprint-protocol.md` |
| `sprint` | 分配时间、复盘效率或调整计划 | 倒计时、今天、这周、打卡、进度、效率、安排 | `sprint-protocol.md` |
| `materials` | 从用户资料建立可追溯学习产物 | PDF、讲义、笔记、题册、索引、学习卡、整理 | `material-protocol.md` |
| `mistake` | 解释既有错误并安排再次验证 | 错题、我选了、答案是、为什么错、加入错题本、二刷 | `error-taxonomy.md` + 学科协议 |
| `verbal` | 解答或训练言语理解 | 主旨、意图、细节、标题、排序、填句、成语、实词 | `verbal-protocol.md` |
| `figure` | 解答或训练图形推理 | 图形、九宫格、位置、样式、数量规律、空间重构 | `figure-protocol.md` |
| `logic` | 解答或训练判断推理 | 定义、类比、翻译、真假、集合、削弱、加强、前提 | `logic-protocol.md` |
| `data-quant` | 解答或训练资料分析/数量关系 | 增长率、比重、平均数、倍数、工程、行程、概率、几何 | `data-quant-protocol.md` |
| `politics` | 讲解或训练政治、常识、公基、时政 | 理论、常识、公基、法律、政策、会议、时政 | `politics-protocol.md`，易变内容加 `official-sources.md` |
| `shenlun` | 阅读材料、作答或批改申论 | 概括、综合分析、对策、应用文、作文、申论 | `shenlun-protocol.md` |

## 冲突优先级

1. **操作覆盖学科**：要求记录/收录错题时用 `mistake`；要求排计划/复盘进度时用 `sprint`；要求整理上传资料时用 `materials`。
2. **错题再调学科**：“这道资料分析错题为什么错”以 `mistake` 为主、`data-quant` 为辅。
3. **材料再调学科**：“根据这份讲义出言语题”先用 `materials` 确认来源和范围，再用 `verbal` 设计训练。
4. **计划再调学科**：“逻辑最近总错，安排下周”先用 `sprint` 依据数据排序，再用 `logic` 写具体训练动作。
5. **最新事实叠加核验**：报名、职位、法律、政策、大纲、时政等内容，无论主路由是什么，都叠加 `source-policy.md`；政治与时政再加 `official-sources.md`。
6. **图像证据优先**：图推图片或错题截图必须先实际查看；无法读取时保留可做的分析并请求文字/清晰局部，不猜图。

## 是否需要追问

只有缺失信息会改变答案、评分或计划时才追问，并尽量只问一个最关键问题。以下情况可先给临时方案：考试日期未知、没有历史数据、没做过模考。以下情况不能猜：缺题干/选项、图片不可辨、申论作答范围缺失、要求精确核验但没有当前官方来源。

## 完成判据

- 解题：结论、证据链、干扰项/替代方法、下次检查。
- 训练：用户先作答，反馈定位第一断点，并给立即变式或间隔回测。
- 计划：主攻方向唯一，任务有时间/数量上限、完成判据和停止条件。
- 批改：要点与材料位置对应，明确证据缺口，不伪造精确分。
- 记录：仅在用户明确要求后执行，返回可继续使用的标识或状态。
