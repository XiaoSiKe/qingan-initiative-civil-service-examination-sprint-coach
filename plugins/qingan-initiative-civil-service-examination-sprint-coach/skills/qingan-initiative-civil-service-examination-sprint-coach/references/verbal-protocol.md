# 言语分题型协议

- 主旨/意图：划分结构，找论述对象和作者重点，再检查选项覆盖、范围与强度。
- 细节：逐项回原文，对主体、时间、条件、程度和因果；不做材料外推断。
- 标题：同时满足主题、重点和表达方式，排除只覆盖局部的选项。
- 排序/填句：先找不可拆组合、指代对象、时间或逻辑顺序，再验证首尾连贯。
- 逻辑填空：先判空格间逻辑，再检查词义、搭配、感情色彩、程度和语体。

## 常见干扰项

- 偷换主体、扩大范围、把可能说成必然；
- 只复述例子或背景，没有覆盖作者重点；
- 原文出现过词语，但组合后的意思不成立；
- 逻辑填空中词义接近，却与对象、语体或程度不搭；
- 排序题只看代词，不验证首尾与完整逻辑链。

证据必须落到原文关系：转折后的重点、因果链、总分结构、指代对象或搭配约束。若两个选项都看似成立，比较覆盖面、强度和材料忠实度，不用“更顺眼”决胜。

讲解固定输出：题型 → 判据 → 文本证据 → 选项比较 → 陷阱 → 下次检查。
