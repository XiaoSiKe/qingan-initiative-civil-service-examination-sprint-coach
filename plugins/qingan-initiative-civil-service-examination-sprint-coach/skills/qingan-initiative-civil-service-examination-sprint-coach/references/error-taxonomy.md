# 错因分类与错因卡

## 分类

| 类型 | 判断依据 | 修正方向 |
|---|---|---|
| knowledge | 不知道规则、概念、公式或事实 | 补最小知识卡后立刻回测 |
| recognition | 学过但没有识别出题型或信号 | 训练识别信号和反例 |
| reading | 主体、时间、范围、否定词或单位读错 | 建立审题检查项 |
| reasoning | 关系链、论证方向或条件转换错误 | 重做关键推理步骤 |
| calculation | 公式、代入、估算、精度或运算错误 | 固定计算顺序与验算 |
| strategy | 做题顺序、时间分配或取舍错误 | 设置止损点和跳题规则 |
| careless | 方法正确且能复现，只在执行中偶发失误 | 增加一个具体检查动作 |
| unknown | 证据不足 | 标低置信并说明缺什么 |

不要把无法解释的错误都归为粗心。

## 定位第一断点

依次检查：知识是否具备 → 是否识别题型 → 是否读对主体/时间/范围 → 推理或计算是否成立 → 时间策略是否合理 → 最后才判断执行失误。找到第一个足以改变答案的断点后停止向后归因，避免把结果错误重复记成多个原因。

置信度使用：题面、用户答案、参考答案和过程都完整时可标高；缺过程但能排除多数原因时标中；截图模糊、答案来源不明或只能猜测时标低/unknown。

## 输出卡

```text
题型：
我的答案 / 参考答案：
第一个错误断点：
错因类型与置信度：
最小修正：
下次固定检查：
变式回测：
来源：
回测日期：
```

## 回测规则

立即变式验证“是否会做”，间隔回测验证“是否记得并能迁移”。`again` 回到首个间隔，`hard` 保持阶段，`good` 前进一阶，`easy` 最多前进两阶。至少两个不同日期的成功回测且达到阶段 2 才标记稳定；重复错时更新第一断点，不沿用旧诊断。
